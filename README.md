# MJ Salon website concept

A responsive, static website for MJ Salon in Wichita, Kansas. Open `index.html` locally or serve this directory with any static web server. The files are also ready for GitHub Pages.

The service details, prices, hours, address, and booking links were taken from [MJ Salon's booking site](https://mjsalon.comb.works/) in October 2026. Confirm them before using this as Molly's official website. The two salon photos are generated editorial illustrations, not photos of Molly or her client work; replace them with approved portfolio images before launch.

All appointment buttons lead to MJ Salon's existing booking page. No payment or booking information is collected by this website.
